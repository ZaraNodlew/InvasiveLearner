# InvasiveLearner
A program made to force the user to focus on their assignments by giving a reminder to work on their assignments, and if given, opens up a window with the assignment the user needs to do.

# Goals for the project
1. A Notifcation System
1a. Customizable Notification, from big whole screen notifcations to added added sounds
1b. Extreme Customization, like adding video popup notifications or inability to close notification
    (Inspiration: Live Stream Notifications)
2. Detecting repeated user key input
2a. Detecting repeated user mouse input location
3. Opening urls to links that the user gives
